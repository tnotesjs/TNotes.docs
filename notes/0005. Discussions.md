# Discussions

## 当前状态

SSG 注册的 `<Discussions />` 只有前往 GitHub Discussions 的占位说明。`tnotes.json` 中的 `discussions` 为预留开关；设置为 `true` 不会自动完成 giscus 接入。

- 当前不存在有效的 `enableDiscussions` 笔记配置。
- 笔记 frontmatter 只使用 `id` 和 `description`；不要恢复 `done`、时间戳、`bilibili` 等旧字段。
- UUID 仍应保留，以维持笔记身份和历史兼容；这不代表当前已有基于 UUID 的评论映射服务。

完整说明见 [扩展语法与组件](./0045.%20Desk%20扩展语法与组件.md) 和 [知识库与笔记配置参考](./0049.%20知识库与笔记配置参考.md)。
