## 1. 本节内容

- 知识库怎么和 GitHub 同步

## 2. 评价

`tnotes --pull` / `--push` / `--sync` 以及 `*All` 批量版本已删除。知识库就是普通 git 仓库。

```bash
git pull
git add -A
git commit -m "…"
git push
```

Desk 里也可以做同样的 git 操作。不要再为「同步笔记」单独装一套 TNotes 脚本。

多库一起推送：对每个 `TNotes.xxx` 分别 push，或自己写循环。工具链不再提供 `tn:pushAll`。
