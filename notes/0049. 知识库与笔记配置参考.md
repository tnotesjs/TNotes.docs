# 知识库与笔记配置参考

> 核对基线：2026-09-15，TNotes Desk 0.8.2 所在源码版本。本文是供后续人工完善的使用说明初稿；已发布旧版本可能与此不同。

## 各类配置文件各管什么

| 文件 | 管理内容 | 是否随知识库共享 |
| --- | --- | --- |
| `tnotes.json` | 库身份、站点、编辑约定 | 是 |
| 笔记顶部 frontmatter | UUID、摘要 | 是 |
| `TOC.md` | 分组、顺序、层级、笔记完成态 | 是 |
| Desk `.tn-desk-config.json` | 当前设备的应用偏好 | 否，见 [应用设置](./0048.%20Desk%20应用设置参考.md) |

`tnotes.json` 是标准 JSON 对象，不能写注释。当前 SSG 不读取 `tnotes.config.ts` 或 VitePress 的配置文件。库级未知字段可以保留，但“保存后还在”不代表当前 Desk 或站点已经使用该字段。

## 库身份与链接

| 字段 | 类型 / 默认 | 用途与边界 |
| --- | --- | --- |
| `name` | 可选字符串 | 仓库式名称，例如 `TNotes.docs`；有效值匹配 `^[A-Za-z0-9._-]{1,100}$` |
| `title` | 可选字符串 | 显示名；Desk 回退到名称/目录，SSG 未设置时用目录名 |
| `description` | 字符串，默认空 | 知识库简介 |
| `icon.src` | 可选字符串 | 图标 URL 或本地资源路径，如 `../assets/.tn-kb-icon.png` |
| `icon.svg` | 可选字符串 | 内联 SVG 图标 |
| `icon.letter` | 可选字符串 | 单字符图标；与 src/svg 三选一更清楚 |
| `repositoryUrl` | 可选字符串 | 仓库链接；配置界面缺省时可从 origin 提示 |
| `rootUrl` | 可选字符串 | 根库地址；当前不因该字段自动收集目录 |
| `pageUrl` | 可选字符串 | 已发布站点地址，供界面打开 |

修改 `name` 不会重命名本地文件夹或 GitHub 仓库；修改 `repositoryUrl` 也不等于执行 `git remote set-url`。实际 Git 远端仍以仓库 `.git/config` 为准。

`pageUrl` 只是公开地址，不负责创建站点。部署路径使用下面的 `base`；两者应一致。

## 站点与 Markdown

| 字段 | 默认值 | 允许值 / 用途 |
| --- | --- | --- |
| `base` | `"/"` | 站点根路径，例如 `/TNotes.docs/`，首尾斜线会规范化 |
| `home` | 未设置 | 首页使用的四位笔记编号字符串；默认 TOC 第一篇笔记 |
| `lang` | `"zh-Hans"` | 页面语言 |
| `port` | `9193` | 本地预览端口，整数 1–65535；被占用时实际地址以启动结果为准 |
| `markdown.lineNumbers` | `true` | 站点普通代码块默认行号；单个围栏可覆盖 |
| `markdown.math` | `true` | 站点公式解析 |
| `markdown.imageLazyLoading` | `true` | 给站点 Markdown 图片启用懒加载 |
| `ignoreDeadLinks` | `false` | `false`、`true` 或字符串数组，控制内链构建检查 |
| `head` | `[]` | 额外 HTML head 标签数组 |
| `theme` | 未设置 | 自定义主题模块，默认导出对象，可提供 `enhanceApp` |
| `discussions` | `false` | 当前预留的评论开关；不会自动生成可用的 giscus 评论框 |

### 构建路径约定

- 输出目录固定为 `.tnotes/dist`。
- 缓存目录固定为 `node_modules/.tnotes-ssg`。
- 静态公开目录固定为 `public/`。
- 库级附件在 `assets/`，构建时复制到站点。

不要在 `tnotes.json` 中添加 `outDir/cacheDir/publicDir` 期望改变这些路径，当前解析器不读取这些覆盖值。

### 内链检查

```json
{
  "ignoreDeadLinks": ["/暂未建立的页面"]
}
```

字符串数组按链接原值**精确匹配**，不是 glob，也不是正则表达式。`true` 会关闭这项检查；默认保留检查更容易发现错误引用。它不是在线检查所有外部网址和图片资源的爬虫。

### head

```json
{
  "head": [
    ["meta", { "name": "author", "content": "作者" }]
  ]
}
```

每项形式为 `[标签名, 属性对象, 可选文本内容]`；属性值使用字符串。自定义脚本或复杂主题属于进阶场景，需要重新构建和预览验证。

### theme

`theme` 指向构建器能解析的模块。例如使用包形式的主题模块时，它需要导出对象，必要时提供 `enhanceApp({ app, site, pages })`。这不是 Desk 的浅色/深色设置，也不是 VitePress 的 `themeConfig`。普通知识库无需填写。

## Desk 的单库编辑约定

| 字段 | 默认 | 作用 |
| --- | --- | --- |
| `prettier` | 未设置，跟随全局 | 布尔值；仅源码视图保存时用 Prettier，库级值覆盖全局 |
| `headingNumberMaxDepth` | 未设置，跟随全局 2 | 整数 1–6，标题编号深度上限 |
| `autoPush.enabled` | 未设置即关闭 | 是否空闲后自动提交推送 |
| `autoPush.idleMinutes` | 配置界面初始 5 | 开启后填写正整数分钟；Desk 配置页限制 1–1440 |

```json
{
  "prettier": false,
  "headingNumberMaxDepth": 2,
  "autoPush": {
    "enabled": true,
    "idleMinutes": 5
  }
}
```

`autoPush` 没有全局默认开关。关闭时可通过配置页移除此项。自动推送会使用当前仓库真实 Git 状态，认证、未保存编辑、冲突或正在执行的事务可能阻止操作；不能理解为无条件定时上传。

## 完成趋势

| 字段 | 默认 | 作用 |
| --- | --- | --- |
| `stats.enabled` | 未设置即关闭 | 允许执行完成趋势回填 |
| `stats.completedNotesCount` | 未设置 | `YY.MM` 到已完成笔记数量的映射 |

```json
{
  "stats": {
    "enabled": true,
    "completedNotesCount": {
      "26.08": 12,
      "26.09": 15
    }
  }
}
```

数值是依据 `TOC.md` 的 Git 历史统计的完成总量，不是当月新增笔记数量。缺失月份会按历史规则补齐；不只保留最近 12 个月。使用 `tnotes-kb update` 维护，不必手工逐月填写。统计未启用时命令报错，不会悄悄启用。

## 笔记 frontmatter：只用两个字段

```md
---
id: 11111111-2222-4333-8444-555555555555
description: 给读者和笔记表格看的摘要。
---

# 笔记标题

## 正文小节
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | 非空字符串，使用 UUID | 新笔记自动生成的稳定身份；保留既有值，不要批量重建 |
| `description` | 非空字符串，可省略 | 供 NotesTable 等展示摘要 |

这里的 UUID 与文件名四位编号不同：`NotesTable.ids` 使用四位编号，frontmatter `id` 使用 UUID。

当前 KB API 解析和序列化只保留上述白名单。不要把完成态、标题、端口、评论开关放进单篇笔记 frontmatter。历史 `done/enableDiscussions/created_at/updated_at/yuque/bilibili` 不属于当前笔记配置；外部链接写在正文即可。

保留 UUID 是为了稳定身份和历史兼容，并不能证明当前站点已经接通按 UUID 映射的评论服务。

## TOC.md：目录与完成状态

```md
- Desk 使用说明
  - [ ] 0043. Desk 使用说明入口与快速上手
    - [ ] 0044. Desk 支持的 Markdown 语法
  - [x] 0049. 知识库与笔记配置参考
```

- 普通 `- 分组名称` 创建分组。
- `- [ ] NNNN. 标题` 表示未完成笔记，`- [x]` 表示已完成。
- 每级缩进两个空格；笔记节点也可以有子节点。
- 排序只由 TOC 决定，编号不随排序改变。
- 单篇笔记只能出现一次；引用不存在的编号会产生诊断。
- 实际文件存在但未收入 TOC 时，也会产生未收录诊断。
- 完成态不读取正文任务列表或 frontmatter。

文件名为 `notes/NNNN. 标题.md`，笔记平铺。根 README 是仓库说明，不是生成目录的依据；站点首页优先使用 `home` 或 TOC 第一篇笔记。

## 可复制的库配置示例

```json
{
  "name": "TNotes.demo",
  "title": "示例知识库",
  "description": "记录学习笔记",
  "repositoryUrl": "https://github.com/your-name/TNotes.demo",
  "pageUrl": "https://your-name.github.io/TNotes.demo/",
  "base": "/TNotes.demo/",
  "home": "0001",
  "lang": "zh-Hans",
  "port": 9193,
  "markdown": {
    "lineNumbers": true,
    "math": true,
    "imageLazyLoading": true
  },
  "prettier": false,
  "headingNumberMaxDepth": 2,
  "stats": { "enabled": true }
}
```

替换示例所属用户、库名和首页编号。新库不需要一次填完所有可选项，先使用 Desk 创建的最小配置，再按需求添加。
