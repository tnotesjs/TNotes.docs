# Desk 支持的 Markdown 语法

## 适用范围

这里列的是当前笔记作者可使用的语法。TNotes 的提示容器和组件另见 [扩展语法](./0045.%20Desk%20扩展语法与组件.md)。GitHub 自身不会渲染所有 TNotes 扩展。

下面的代码围栏用于展示写法。示例中的附件名需要替换成实际文件，不能原样复制后期望图片出现。

## 普通 Markdown

| 内容   | 写法                     | 说明                      |
| ---- | ---------------------- | ----------------------- |
| 标题   | `#` 至 `######` 后加空格和文字 | 共六级；正文通常从 H2 开始         |
| 段落   | 段落之间留空行                | 单次换行不一定显示成新段落           |
| 粗体   | `**文字**`、`__文字__`      | 可用工具栏操作，优先推荐 `**`       |
| 斜体   | `*文字*`、`_文字_`          | 可用工具栏操作，优先推荐 `*`        |
| 删除线  | `~~文字~~`               | 可用工具栏操作                 |
| 行内代码 | `` `代码` ``             | 内容按字面显示                 |
| 引用   | `> 文字`                 | 支持多行、嵌套                 |
| 无序列表 | `- 文字`、`* 文字`、`+ 文字`   | 缩进表示子项                  |
| 有序列表 | `1. 文字`                | 支持嵌套；                   |
| 任务列表 | `- [ ] 待办`、`- [x] 完成`  | 正文复选框不改变整篇笔记的完成态        |
| 分割线  | 独占一行的 `---`、`***`      | 前后留空行，避免与其他结构混淆         |
| 硬换行  | 行尾两个空格、反斜杠，或 `<br />`  | 独占一行的 `<br />` 也可保留空白间隔 |
| 转义   | `\*`、`\_` 等            | 把 Markdown 标记作为文字显示     |

<br />

兼容 Setext 标题（下一行 `===` / `---`），新内容统一使用 `#` 标题更容易维护。不要把未实现的脚注、下标/上标快捷语法等当作已支持的 TNotes 扩展；需要时使用经站点预览确认的 HTML。

### 表格

```md
| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| 普通文字 | **粗体** | `代码` |
| 第二行 | 单元格内<br>换行 | 123 |
```

使用工具栏“表格”插入，再通过表格控件编辑行列。普通 Markdown 表格及单元格中的 `<br>` 换行可使用原生表格编辑；含其他 HTML 标签的表格会被隔离为原始块，需要切到源码视图修改。复杂合并单元格不属于普通 Markdown 表格语法。

## 链接

```md
[外部链接](https://example.com)

[同库笔记](./0049.%20知识库与笔记配置参考.md)

[参考式链接][config]

[config]: ./0049.%20知识库与笔记配置参考.md
```

路径中有空格时使用 `%20`。同库笔记链接可由 Desk 选择笔记插入；站点构建时会转换为笔记路由。笔记编号和 UUID 都应保持稳定。跨库链接直接使用对应库的公开站点地址。

还支持尖括号自动链接，如 `<https://example.com>`、`<name@example.com>`；SSG 开启自动链接识别，正文中的普通网址也可能成为链接。需要确定显示文字与目标时，优先显式 Markdown 链接。

站点标题锚点采用 GitHub 风格生成；重名或含标点的标题应在预览中确认锚点。外部 HTTP(S) 链接在站点中以新窗口方式打开。

## 图片、说明、宽度和对齐

```md
![图片说明](../assets/0044-demo.png)

![图片说明](../assets/0044-demo.png "鼠标悬停文字") {w=50% align=center}

![](../assets/0044-demo.png) {width=400px a=right}
```

图片应独占段落，属性紧跟图片，写在同一行。独占段落的 alt 文字用作图片说明；title 是悬停提示。

| 属性 | 值 | 默认与别名 |
| --- | --- | --- |
| `w` | `50%`、`400px` | `width` 为别名；不写按自然宽度并受容器限制 |
| `align` | `left`、`center`、`right` | 默认 `left`；`a` 为别名，`middle` 兼容为居中 |

百分比范围为大于 0 且不超过 100；裸数字如 `50` 按百分比处理。像素宽度至少 16px。高度随图片比例变化，不提供 `{h=...}` 扩展。

标准参考式图片和带链接的图片仍可写入 Markdown；宽度和对齐扩展推荐使用上面这种独占段落的直接图片写法。

库级附件使用 `../assets/`，这样从 `notes/` 查看文件时路径也成立。SSG 兼容旧 `./assets/` 写法，不建议在新笔记中继续复制这种路径。

## 代码块

使用三个反引号或波浪线围住内容，起始围栏后填写语言。也支持缩进至少四个空格的普通代码块，但需要语言、标题等元信息时使用围栏。未知语言会按普通文本显示。

````md
```ts:line-numbers=10 {2,4-5} [example.ts]
const first = 1
const second = 2
const third = 3
const fourth = 4
const fifth = 5
```

```text:no-line-numbers [输出]
操作完成
```
````

| 部分 | 含义 |
| --- | --- |
| `ts` / `js` / `json` / `bash` / `text` 等 | 高亮语言；基于内置 Shiki 语言集 |
| `[example.ts]` | 代码块标题，通常写文件名 |
| `:line-numbers` | 显示行号 |
| `:no-line-numbers` | 隐藏行号，优先于显示设置 |
| `:line-numbers=10` | 行号从 10 开始 |
| `{2,4-5}` | 高亮代码内容的第 2、4、5 行，不按显示起始行号偏移 |

站点默认显示行号，可在 `tnotes.json` 的 `markdown.lineNumbers` 关闭。代码块本身仍可覆盖这个默认值。

当前源码有语言预加载边界：形如 `ts:line-numbers=10` 的语言名加冒号元信息、或波浪线围栏，可能没有被预加载器识别；若同一构建中没有普通围栏加载该语言，会回退为无颜色文本。行号、标题和高亮行元信息仍可生效。需要确认实际颜色时以构建结果为准。

标题左侧可折叠代码块。折叠只隐藏内容，保留标题；重新进入页面默认展开，不写入 Markdown。代码保持原有换行，长行横向滚动，整体高度由内容决定。

`title="a.js"` 不是当前代码块标题的标准元信息，请写 `[a.js]`。`// [!code ++]`、`// [!code focus]` 等 VitePress/Shiki 注释指令没有接入，不能当作差异高亮或聚焦功能。

## 数学公式

```md
行内公式：$a^2+b^2=c^2$。

$$
E = mc^2
$$
```

站点默认启用数学公式，`markdown.math: false` 可关闭 SSG 的公式解析。可视化编辑使用自己的公式编辑能力，站点使用 MathJax；复杂公式以站点预览为准。LaTeX 语法并不意味着整个 LaTeX 文档系统或任意宏包都可使用。

表格单元格中也可写行内公式，含竖线时注意 Markdown 表格分隔符的转义。

Desk 还会对手写的 `latex` 代码围栏做公式预览，但保留其代码围栏来源；SSG 不将 `latex` 围栏转换为数学公式。需要编辑器与发布站点都显示公式时，使用 `$…$` / `$$…$$`，不要用 Desk 中的预览效果推断发布语法。

## HTML、Vue 与字面量

普通 HTML 可以写入笔记；未适配的 HTML 块需切到源码视图修改，能在站点显示不等于可用原生可视化控件编辑。

- 正文的 `{{ count }}` 显示为文字，不作为 Vue 插值执行。
- 内置组件不需要在每篇笔记中导入，但“已注册”不等于其所有浏览器交互已接入。
- 自定义 Vue 组件可以用 `<script setup>` 导入，再以组件标签使用；组件内部可计算插值，通过 props 提供数据。
- **默认 SSG 将正文输出为服务端渲染的 HTML，不会把整篇正文重新挂载为 Vue 应用。** 自定义组件的按钮事件、响应式更新不会因为放进 `.vue` 文件就自动生效；需要宿主另行接入客户端行为，不是普通笔记配置能力。
- 当前正文明确补回的交互包括代码块、代码组、轮播，以及标准围栏生成的 Mermaid/Mindmap 图。直接写同名 Vue 标签不等同于使用对应围栏。
- `<<< 文件路径`、`<!--@include: ...-->`、VitePress 的 frontmatter 页面布局不属于当前已实现语法。

笔记 frontmatter 和 `TOC.md` 的写法见 [配置参考](./0049.%20知识库与笔记配置参考.md)，它们负责元数据与目录，不是额外的渲染插件配置。
