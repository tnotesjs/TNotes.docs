# Desk 历史说明修订对照

## 这篇笔记的用途

docs 中既有早期 VitePress/core 教程，也有后来只更新了一部分的说明。阅读时优先使用 [Desk 使用说明入口](./0043.%20Desk%20使用说明入口与快速上手.md) 下的语法、命令和配置参考。

本轮以当前源码的实际入口、配置读取和渲染行为为准；源码里的 TODO、类型注释、架构计划和旧 README 不能单独证明功能已可用。

## 已确认的差异

| 历史描述或容易误读的说法 | 当前结论 | 对应资料 |
| --- | --- | --- |
| 每篇笔记一个文件夹和一份 `.tnotes.json` | 笔记平铺到 `notes/NNNN. 标题.md`；库配置为 `tnotes.json` | 0043、0049 |
| `done`、`yuque`、`bilibili`、时间戳是笔记配置 | 当前 frontmatter 白名单为 `id/description`；完成态看 TOC | 0049 |
| `enableDiscussions: true` 自动挂载 giscus | 当前没有这个配置；`discussions` 是预留字段，组件仍是占位文字 | 0005、0045、0049 |
| Desk 与站点完全使用同一编辑/渲染引擎 | 可视化编辑与 SSG 不同；发布效果用站点预览核对 | 0043、0044 |
| Desk 与站点中的脑图一律只读 | Desk 可编辑适配的脑图块并回写，站点默认只读 | 0013、0045 |
| 用 `<<<` 引入外部脑图或代码 | 当前 SSG 没有该导入语法 | 0044、0045 |
| `/mmd` 就是应保存的围栏语言 | 输入别名转为 `mermaid`；文件中的 `mmd` 展示源码 | 0045、0046 |
| `:::error` 是正式容器 | 编辑器快捷输入转成 `::: danger` | 0045、0046 |
| 代码块用 `title="..."` 或 `[!code focus]` 设置显示 | 标题写 `[文件名]`；代码注释指令未接入 | 0044 |
| 所有旧 `tnotes --xxx` 命令仍可用 | 目前只有 KB 的 init/update/help 与 SSG 的 dev/build/preview | 0047 |
| `tnotes-ssg --help` 可显示帮助 | 当前会报未知命令 | 0026、0047 |
| `tnotes-kb update` 会重建整个知识库 | 只回填完成趋势；统计关闭时会报错 | 0047、0049 |
| 修改 `name/repositoryUrl` 就能改名或修改 remote | 它们不重命名本地/GitHub 仓库，也不替代 Git remote 操作 | 0049 |
| `rootUrl` 会自动把子目录汇总到根站 | 该字段当前不执行收集；根站收集靠单独工作流 | 0047、0049 |
| `defineConfig` 导出意味着 SSG 自动读取 TS 配置 | CLI 当前只读取 `tnotes.json` | 0049 |
| 架构里提及 Desk 无头 CLI 就能直接调用 | 当前没有面向用户的独立 Desk build/help CLI | 0047 |
| 自由绘图会发布为内置 Excalidraw 组件 | 当前保留 `.excalidraw` 与同名 SVG，站点展示 SVG | 0045 |
| Prettier 对所有视图生效并读 `.prettierrc` | 只在源码保存时按内置默认风格格式化 | 0048 |
| `oxipng`、最大边尺寸都已经是可用图片设置 | oxipng 未接入；最大边字段当前固定归一为空 | 0048 |
| 所有工具都在独立 desk/kb/ssg/ui 仓库 | 现位于 `tnotesjs/tnotes` 的 apps/packages 下 | 当前说明的核对依据 |
| 基础斜杠菜单含图片，共 16 项 | 生产配置关闭基础图片项：15 项基础 + 15 项 TNotes 扩展 | 0046 |
| 设置页显示的快捷键在两种视图完全一致 | 部分提示与真实绑定不一致，列表和引用等须区分视图 | 0046 |
| 内置组件注册后自动恢复所有网页交互 | 正文默认 SSR，仅指定块补回交互；WordList/Footprints 不能照搬旧站点交互 | 0044、0045 |
| 自定义组件导入后按钮和响应式更新自动可用 | 可参与 SSR，但没有整篇正文 Vue 挂载；需额外客户端接入 | 0044、0045 |
| 应用设置保存失败会覆盖成默认值 | 保存/导入严格校验；读取磁盘配置才做容错与默认回退 | 0048 |
| `tnotes-kb update --help` 可安全查看帮助 | 可能实际执行更新；帮助参数应紧跟命令名 | 0047 |
| Pages 脚手架生成后统计步骤直接可运行 | 新配置须开启 stats，或删除工作流中的统计步骤 | 0047 |

## 旧笔记怎么处理

- 保留历史设计、个人经验和旧截图，不把它们当作当前操作清单。
- 旧命令专题增加入口提示，读者可跳到统一 CLI 参考，减少多个地方分别维护参数。
- 评论相关技术原理作为历史资料；当前是否可用由状态说明明确标出。
- 既有组件示例仍可用于人工体验，完整当前语法查 0044、0045。
- 新参考笔记在 TOC 暂时保持未完成，便于后续人工审阅。

## 后续人工复核建议

1. 按自己正在使用的 Desk 安装版本逐项体验；本轮核对的是 0.8.2 所在源码，不代表所有历史安装包。
2. 补充打开知识库、斜杠菜单、资源整理、图床、Git 和站点预览的实际截图。
3. 逐步更新旧组件演示中的截图、交互描述和已失效链接。
4. 根据发布节奏维护一次版本基线，尤其是评论、图床编码器和自定义组件等边界功能。
5. 日后有新语法、命令或设置，优先维护这组统一参考，再同步具体教程。

这份对照表不是未来功能承诺。只有实际实现和验证后，才应把“预留”“未接入”改为“支持”。
