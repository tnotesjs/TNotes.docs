`pnpm tn:build` 现在调用 `tnotes-ssg build`，产物在 `.tnotes/dist`。GitHub Pages 工作流也是这一步，不再走 VitePress。

## 3. 本地构建

```bash
pnpm tn:build
# 等价于
pnpm exec tnotes-ssg build
```

成功时会打印类似：

```txt
TNotes SSG built 42 pages into /path/to/TNotes.docs/.tnotes/dist
```

页数 = 首页 + 404 + 每篇在 `TOC.md` / `notes/` 里的笔记。

## 4. CI 里做什么？

`.github/workflows/deploy.yml`：

1. `pnpm install`
2. `pnpm tn:update`（回填统计）
3. `pnpm tn:build`
4. 上传 `.tnotes/dist` 到 GitHub Pages

Node 22、pnpm 11。

## 5. 构建失败常见原因

`tnotes-ssg` 会检查能够提取的 Markdown 内部链接，但当前提取器排除图片，也不是外部网址、参考式链接或 HTML 标签的完整爬虫。因此 `![](../assets/不存在.png)` 不保证导致构建失败，构建成功也不等于图片全部有效。

另外用 Desk 资源面板检查缺失附件，并在站点预览中核对图片。要展示不存在的路径，只写在代码块里，不要写成真正的图片语法。工作流若开启 `tn:update`，还需要 `stats.enabled: true` 和可读取的 TOC Git 历史。
