# help

## 当前帮助入口

旧 `tnotes --help` 已随 core CLI 停用。在安装相应依赖的知识库目录执行：

```bash
pnpm exec tnotes-kb --help
pnpm exec tnotes-kb -h
```

不带任何参数也打印 KB 帮助，但退出码为 1；脚本中应使用显式 `--help`。帮助参数必须紧跟可执行命令，不要写成 `tnotes-kb update --help`，后者可能实际执行统计更新。

## SSG 没有 help 参数

**当前 `tnotes-ssg --help` 会报未知命令**，不是有效帮助入口。实际支持的子命令只有：

```bash
pnpm exec tnotes-ssg dev
pnpm exec tnotes-ssg build
pnpm exec tnotes-ssg preview
```

各命令可在子命令后提供知识库目录，完整参数与限制见 [TNotes CLI 命令参考](./0047.%20TNotes%20CLI%20命令参考.md)。

## Desk 操作帮助

Desk 没有单独的 `help` 面板命令。使用 [快速上手](./0043.%20Desk%20使用说明入口与快速上手.md)、[命令与快捷键](./0046.%20Desk%20命令与快捷键.md) 和设置页查阅操作。
