## 2. TNotes 简介

[TNotes][10] 诞生于 `2024.08.28`，它是一个开源的知识库管理工具。

- 日常编辑走 [TNotes Desk][11]
- 站点构建走 `@tnotesjs/ssg`
- 目录和配置走 `@tnotesjs/kb`
- UI 组件统一封装在 `@tnotesjs/ui`
- 评论功能走 [giscus](https://giscus.app/zh-CN)

若有分享需求，可将知识库部署到 [GitHub Pages](https://pages.github.com/) 中。

在根知识库 [TNotes.root][6] 中，你可以访问到所有已发布的知识库。但凡是在 TNotes 中能看到的内容，均已开源在 [tnotesjs github][5] 上，有需要的可自行 clone。

## 3. 「知识库」和「笔记」

```mindmap [「知识库」和「笔记」]
- 知识库（kb）
  - kb 本质上就是一个简单的文件夹
  - kb 配置文件
    - 文件夹的根目录下有一份 `tnotes.json` 配置文件，这是 kb 的配置。
  - git 仓库
    - 你也可以将 kb 初始化为一个 git 仓库
    - 作用1 - 版本管理功能：TNotes Desk 支持笔记历史版本回退功能，它会解析 git 历史，提取出你每次对这篇笔记执行 commit 时的笔记版本快照。
    - 作用2 - 分享功能：可以利用 GitHub pages 这样的工具对外公开分享你的 kb。
- 笔记（notes）
  - 是 `notes/` 目录下从 `0001` 起编号的平铺单文件，例如 `notes/0001. TNotes 简介.md`，编号只增不改、不重排。
  - 笔记在知识库中的相对位置统一由根目录下的 TOC.md 来记录。
  - 每篇笔记在创建时都会生成一个全局唯一 id，用于标识笔记身份，目前主要消费链路是关联 giscus 评论。
```

### 3.1. 「知识库」基本结构

这里以当前 `TNotes.docs` 为例：

```bash
# .
# ├── tnotes.json          # 知识库配置，包括：库名、标题、端口、Pages 地址、统计、评论开关
# ├── TOC.md               # 知识库目录
# ├── notes/               # 笔记目录
# │   ├── 0001. TNotes 简介.md
# │   ├── 0002. TNotes 公式支持.md
# │   └── ……
# ├── assets/              # 笔记资源：比如图片啥的
# ├── package.json         # NPM 包体描述文件，这是一个可选的文件
# └── .github/workflows/deploy.yml   # 可选：tnotes-ssg → .tnotes/dist → Pages
```

日常读写优先推荐用 Desk 来管理这个目录。

### 3.2. 「知识库」的类型及其之间的关系

目前在 TNotes 中只有两种类型的知识库：「根知识库」和「子知识库」。

- 根知识库：只有一个，汇总所有子知识库的目录信息，充当统一访问入口。
- 子知识库：可以有多个，每个子知识库独立访问、独立部署。

### 3.3. 关于 `package.json` 的一些补充说明

`package.json` 主要用于集成 `@tnotesjs/kb`、`@tnotesjs/ssg`：

- 如果你更喜欢 vitepress 那样的风格，可以通过 `tn:dev` 命令在本地启动服务来编写 kb，你改动 `notes/` 下的笔记，预览页面会实时刷新，这种做法的好处是可以直接脱离 TNotes Desk 来维护你的 kb，你可以在其他 IDE（比如 VSCode、Curosr）来管理 kb。
  - 新建知识库、新建笔记、改目录，优先在 Desk 里做，同时也会逐步完善 `tnotes/nav`（一个 VSCode 插件），适当减少 kb 的管理对 Desk 的依赖。
- 如果你要在本地测试 ssg 静态站的生成效果，可以先跑 `tn:build` 再跑 `tn:preview`，这就是 `TNotes.*` kb 分享到 GitHub Pages 之后，用户看到的效果。

下面以 `TNotes.docs/package.json` 文件内容为例：

```json [package.json]
{
  "private": true,
  "type": "module",
  "scripts": {
    "tn:update": "tnotes-kb update",
    "tn:build": "tnotes-ssg build",
    "tn:dev": "tnotes-ssg dev",
    "tn:preview": "tnotes-ssg preview"
  },
  "devDependencies": {
    "@tnotesjs/kb": "^0.5.2",
    "@tnotesjs/ssg": "^0.3.3"
  },
  "packageManager": "pnpm@11.10.0",
  "engines": {
    "node": ">=22"
  }
}
```

| 脚本              | 实际命令             | 用途                                 |
| ----------------- | -------------------- | ------------------------------------ |
| `pnpm tn:update`  | `tnotes-kb update`   | 按 TOC Git 历史回填月度完成总数 |
| `pnpm tn:build`   | `tnotes-ssg build`   | 静态站，产物在 `.tnotes/dist`        |
| `pnpm tn:dev`     | `tnotes-ssg dev`     | 无 Desk 时的本地站点                 |
| `pnpm tn:preview` | `tnotes-ssg preview` | 预览已构建产物                       |
