# Desk 命令与快捷键

> 核对基线：2026-09-15，TNotes Desk 0.8.2 所在源码版本。本文是供后续人工完善的使用说明初稿；已发布旧版本可能与此不同。

## 先区分三类命令

| 类型 | 入口 | 例子 |
| --- | --- | --- |
| Desk 命令面板 | `Mod+Shift+P`，输入框以 `>` 开头 | `>资源`、`>全部折叠标题` |
| 编辑器插入命令 | 可视化编辑器空段落输入 `/` | `/tip`、`/mmp` |
| 终端命令 | 系统终端 | `tnotes-kb init`，见 [CLI 参考](./0047.%20TNotes%20CLI%20命令参考.md) |

本文 `Mod` 在 macOS 表示 Command，在 Windows/Linux 表示 Ctrl；`Alt` 在 macOS 对应 Option。组合键之间用 `+`；`Mod+K → U` 表示先按前一组，再按 U，不是同时按所有键。

## 命令面板：当前注册的全部 18 项

| 命令名称 | 数量 | 作用与条件 |
| --- | --- | --- |
| 全部折叠标题 | 1 | 收起当前可处理的编辑器标题 |
| 全部展开标题 | 1 | 展开当前可处理的编辑器标题 |
| 折叠 1 级标题至折叠 6 级标题 | 6 | 每个级别是独立命令 |
| 展开 1 级标题至展开 6 级标题 | 6 | 每个级别是独立命令 |
| 保存当前笔记 | 1 | 保存当前活动笔记 |
| 资源 | 1 | 打开当前知识库的资源面板，需要已选库 |
| 知识库配置 | 1 | 打开当前库的配置，需要已选库 |
| 打开设置 | 1 | 打开 Desk 全局设置 |

折叠类命令只在当前编辑器支持标题折叠时可用；禁用项目不会执行。

`Mod+P` 进入当前知识库的笔记搜索，不以 `>` 开头时属于笔记查找模式。命令匹配名称、关键词和英文别名；键入 `>` 切换到命令列表，方向键选择、Enter 执行、Escape 关闭。

这里没有 `build`、`pushAll`、`sync-scripts` 之类的 Desk 面板命令。

## 斜杠菜单

通常在可视化编辑器空段落输入 `/`，搜索项目后确认插入。匹配也接受标题节点，但要求光标在节点末尾，且不在列表或代码块上下文中。

生产配置的基础菜单共 **15 项**：正文、H1–H6、引用、分割线、无序列表、有序列表、任务列表、代码块、表格、数学公式。基础“图片”项当前关闭，图片使用粘贴或资源入口插入。另有下表 **15 项 TNotes 扩展**，合计 30 个菜单项；其中普通代码块有两个入口，不代表 30 种不同语法。

| 输入词 | 插入内容 | 可搜索别名 |
| --- | --- | --- |
| `/tip` | 提示块 | tip、提示 |
| `/info` | 信息块 | info、信息 |
| `/warning` | 警告块 | warning、警告 |
| `/error` | `danger` 错误块 | error、danger、错误 |
| `/details` | 折叠细节块 | details、细节 |
| `/code` | 普通代码块 | code、代码 |
| `/code-group` | 代码标签组 | code-group、代码组 |
| `/swiper` | 图片轮播 | swiper、轮播 |
| `/N` | NotesTable 笔记表格 | NotesTable、笔记表格 |
| `/B` | BilibiliVideo | bilibili、视频 |
| `/E` | WordList | WordList、单词 |
| `/F` | Footprints | Footprints、足迹 |
| `/mmd` | Mermaid 图 | mermaid、流程图 |
| `/mmp` | Mindmap 脑图 | mindmap、mm、思维导图 |
| `/ex` | Excalidraw 画布 | excalidraw、canvas、draw、画布 |

提示/容器类还可用 `:::tip`、`:::info`、`:::warning`、`:::error`、`:::danger`、`:::details`、`:::code`、`:::code-group`、`:::swiper` 搜索；视频还接受 `BilibiliVideo`，画布还接受“绘图”。这里的词用于菜单搜索，不是可直接执行的终端命令。

插入后补齐视频 ID、笔记编号、图片路径等。模板里的空字符串和示例附件不是实际资源。

## 块级快速输入

以下简写只在可视化编辑器中触发。源码文件本身应保存转换后的正式语法。

| 输入 | 触发键 | 转换结果 |
| --- | --- | --- |
| `:::tip`、`:::info`、`:::warning` | Enter | 对应提示容器 |
| `:::error`、`:::danger` | Enter | `danger` 容器 |
| `:::details` | Enter | 细节容器 |
| `:::code-group` | Enter | 代码组 |
| `:::swiper` | Enter | 轮播 |
| `:::code` | Enter | 普通代码围栏 |
| 三个反引号后跟 `mermaid` 或 `mmd` | Enter 或空格 | `mermaid` 围栏 |
| 三个反引号后跟 `mindmap` 或 `mmp` | Enter 或空格 | `mindmap` 围栏 |
| 空段落中的 `···`（三个中文间隔号） | 输入完成时 | 普通代码块 |

除了以上 TNotes 自定义规则，实际装配的编辑器还继承下列 Markdown 输入规则：

| 输入 | 触发与结果 |
| --- | --- |
| `#` 至 `######`、`>`、`-` / `*` / `+`、`1.` 等 | 后加空格，转换为标题、引用或列表 |
| `$$` | 后加空格，创建块级公式；新公式保存为 `$$` 语法 |
| `\|3x2\|` 或 `\|3X2\|` | 后加空格，创建 3 列 2 行表格；顺序为列 × 行，至少两行 |
| 三个反引号，可跟小写语言名 | 后加空格，创建普通代码块 |
| 已有列表项内的 `[ ]` 或 `[x]` | 后加空格，转换为未完成 / 已完成任务项 |
| `---` | 第三个连字符输入完成后转换为分割线 |
| `***` 或 `___` | 后加空格转换为分割线 |

成对输入 `*文字*` / `_文字_`、`**文字**` / `__文字__`、`~~文字~~`、行内代码或 `$公式$` 后按空格，可触发对应行内格式。快速输入不是新发布语法，例如直接把 `\|3x2\|` 留在文件中不会生成站点表格。

## 标签与导航快捷键

| 操作 | 快捷键 |
| --- | --- |
| 关闭当前标签 | `Mod+W` |
| 关闭已保存笔记 | `Mod+K → U` |
| 全部关闭 | `Mod+K → W` |
| 将预览标签保持打开 | `Mod+K → Enter` |
| 固定 / 解除固定 | `Mod+K → Shift+Enter` |
| 下一个标签 | `Ctrl+Tab` |
| 上一个标签 | `Ctrl+Shift+Tab` |
| 当前标签组内第 1–9 个标签，含固定标签 | `Mod+1` 至 `Mod+9` |
| 复制笔记目录路径 | `Alt+Mod+C` |
| 在系统文件管理器中显示 | `Alt+Mod+R` |
| 搜索当前知识库笔记 | `Mod+P` |
| 命令面板 | `Mod+Shift+P` |

`Mod+K` 后有约 1.5 秒等待后续键。关闭操作有保护规则：“全部关闭”关闭各组未固定标签；“关闭已保存笔记”排除网页、未保存和固定标签；`Mod+W` 不关闭固定标签，且无活动标签时可能关闭窗口。

预览标签是临时打开的标签，不等同于 SSG 站点预览。需要长时间保留时使用“保持打开”或固定。

## 编辑快捷键

| 操作 | 快捷键 |
| --- | --- |
| 保存 | `Mod+S` |
| 撤销 / 重做 | `Mod+Z` / `Mod+Shift+Z` |
| 一级至六级标题 | `Alt+Mod+1` 至 `Alt+Mod+6` |
| 正文段落 | `Alt+Mod+0` |
| 粗体 / 斜体 | `Mod+B` / `Mod+I` |
| 删除线 | `Mod+Shift+X` |
| 清除当前行或选中行的粗体、斜体、删除线 | `Mod+\`，仅笔记 |
| 行内代码 | `Mod+E` |
| 有序列表 / 无序列表 | 可视化：`Alt+Mod+7` / `Alt+Mod+8`；源码：`Mod+Shift+7` / `Mod+Shift+8` |
| 任务列表 | 源码：`Alt+Mod+T`；可视化用菜单或输入规则，无对应已注册快捷键 |
| 引用 | 可视化：`Mod+Shift+B`；源码：`Alt+Mod+U` |
| 分割线 | 源码：`Alt+Mod+S`；可视化用菜单或输入规则，无对应已注册快捷键 |
| 应用缩放增减 10% | `Mod++` / `Mod+-` |
| 恢复应用 100% | `Mod+0` |

快捷键针对当前焦点及可编辑状态生效。当前设置页/工具栏中的部分提示与实际绑定不一致，上表区分了源码与可视化的真实键位；不要仅按提示推断支持。

### 可视化编辑与块内快捷操作

| 操作 / 场景 | 实际绑定与边界 |
| --- | --- |
| 当前编辑器全选 | `Mod+A`；可视化全选后删除保留锁定的 frontmatter、引用定义等原子块 |
| 删除线兼容键 | `Alt+Mod+X`，可视化编辑器保留的另一绑定 |
| 重做兼容键 | `Mod+Y`，可视化编辑器历史插件 |
| 硬换行 | `Shift+Enter` |
| 列表缩进 / 反缩进 | `Tab` / `Shift+Tab` 或 `Mod+]` / `Mod+[`，依列表上下文生效 |
| 表格下一格 / 上一格 | `Tab` / `Shift+Tab`，焦点在表格内时 |
| 退出表格 | `Mod+Enter`，表格上下文 |
| 标题行首回正文 | Backspace 一次直接转换为段落，不逐级降标题 |
| 嵌入代码块多选 | `Mod+D` 选择下个相同文本；Alt-click 添加光标；Alt-drag 或鼠标中键拖动进行矩形选择 |

嵌入代码编辑器、画布和脑图有自己的焦点行为；上述块内快捷操作不是所有 Desk 视图的统一命令。源码视图由 Monaco 提供其他原生编辑操作，本参考优先列出 Desk 显式绑定与常用上下文操作。

## 工具栏、右键菜单和专用面板

这些是当前功能入口，不一定注册为 `>` 命令。

| 位置 | 可做的操作 |
| --- | --- |
| 知识库列表与目录侧栏 | 新建知识库、笔记、分组；重命名；调整顺序与嵌套；切换完成态；隐藏或显示库 |
| 笔记格式工具栏 | 粗体、斜体、删除线、行内代码、标题/正文、引用、列表、任务列表、链接、代码块、分割线、表格 |
| 标题工具 | 标题编号重排、移除编号；编号上限由设置控制 |
| 笔记视图工具 | 可视化、只读、源码；页宽；笔记内目录；本笔记资源 |
| 知识库操作入口 | 知识库配置、资源、站点预览、Git 相关操作 |
| Git / 历史面板 | 查看变更和历史、比较、提交推送、恢复计划；可用操作受 Git 状态影响 |
| 知识库资源面板 | 扫描、查看引用、重命名、回收、合并同笔记重复资源、优化图片、查看恢复记录 |
| 本笔记资源面板 | 定位正文引用、插入附件、重命名、移除无效资源、修复归属编号 |
| 图片、代码块、导图和画布 | 使用块旁专用控件编辑或预览；可用项随块类型和只读状态变化 |
| 设置 → 配置文件 | 保存并校验、导入、导出、恢复默认 |

危险或可能覆盖内容的操作以界面显示的计划、确认框和禁用原因作为最终依据。
