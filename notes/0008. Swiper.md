```mindmap
# Swiper 组件

- Swiper 是一个图片的容器
- 基于开源项目 [Swiper](https://github.com/nolimits4web/swiper) 封装而来
- 参考 LeetCode 中的步骤图解来实现的
```

使用示例：

```md
::: swiper

![1](../assets/0008-1.png)

![2](../assets/0008-2.png)

![3](../assets/0008-3.png)

![4](../assets/0008-4.jpg)

![5](../assets/0008-5.png)

:::
```

其中图片的 alt（比如 `![1](...)` 中的 `1`）就是 tab 的标题。
