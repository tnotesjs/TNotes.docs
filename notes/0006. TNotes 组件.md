# TNotes 组件

完整当前语法见 [Desk 扩展语法与组件](./0045.%20Desk%20扩展语法与组件.md)，普通 Markdown 见 [Markdown 语法](./0044.%20Desk%20支持的%20Markdown%20语法.md)。本章节保留演示与历史截图；部分旧页面的交互曾基于 VitePress，不能直接视为当前 Desk 或 SSG 的功能承诺。

共享组件位于 `tnotesjs/tnotes` 的 `packages/ui`，Desk 在 `apps/desk`，SSG 在 `packages/ssg`。组件被复用不意味着两端编辑、渲染和交互完全一致，尤其应区分静态 HTML 与已接入的浏览器交互。

本章节下的笔记除了对核心组件的使用做一个简单的介绍之外，还有另一个作用：开发阶段，测试组件是否能够正常工作。
