在最新的 TNotes 架构里，kb 的配置主要分两层：

- kb 层：根目录 `tnotes.json`
- notes 层：每个 `notes/NNNN. 标题.md` 顶部的 YAML frontmatter

## 1. `tnotes.json` 常见字段

| 字段 | 作用 |
| --- | --- |
| `name` | 仓库名，如 `TNotes.docs` |
| `title` | Desk 列表和站点显示名 |
| `description` | 一句话简介 |
| `icon.src` | 图标 URL 或 `../assets/.tn-kb-icon.*` |
| `port` | Desk 预览 / `tnotes-ssg` 端口（本库 `10107`） |
| `pageUrl` | GitHub Pages 地址 |
| `repositoryUrl` | GitHub 仓库地址 |
| `base` | 站点 base，Pages 上一般是 `/TNotes.docs/` |
| `home` | 首页用哪一篇笔记编号；默认 TOC 第一篇 |
| `discussions` | 当前预留评论开关，不会自动接入 giscus |
| `stats.enabled` | 是否允许 `tnotes-kb update` 回填完成数 |
| `stats.completedNotesCount` | `YY.MM` → 当月已完成笔记数 |

可在 Desk 的知识库配置页改，也可以直接改文件。

## 3. 旧的 `yuque` 字段

早期每篇笔记的 `.tnotes.json` 里有过 `yuque` 数组，用来挂语雀链接。新模型不再读这个字段。需要外链时直接写在正文里即可。
