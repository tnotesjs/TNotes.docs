# Mindmap 组件

- 简介
  - Mindmap 是 TNotes 中的思维导图组件
  - 交互体验参考「幕布」设计
- 核心特点
  - 以 markdown 无序列表作为唯一真相源
- 语法约束
  - 围栏名称是 `mindmap`
  - 展开层级直接写为正整数，例如 `mindmap 2`
  - 定义根主题：
    - 围栏 \[title\]
    - 内容 H1

  - 无序列表真相源

  - 碍于「markdown 无序列表真相源」这一限制，能插入的元素类型比较有限。
  - ✅ H1 标题

## 1. Mindmap 预览

TNotes 的 Mindmap 预览由 [`@tnotesjs/mindmap-core`][mindmap-core] 提供解析、数据模型和画布渲染能力，由 Desk / `@tnotesjs/ssg` 挂到笔记页上。

预览组件默认展示脑图视图，同时提供：

- **脑图**：支持平移、缩放、适应视口、折叠/展开、进入主题和打开链接。
- **大纲**：以只读树形大纲查看相同数据。
- **源码**：查看实际交给 `mindmap-core` 的规范化 Markdown。
- **主题同步**：亮色、暗色会自动跟随当前站点主题。

发布站点中的 Mindmap 默认只读；Desk 中已适配的脑图块则提供编辑入口，修改会回写 Markdown 围栏。两者不能统称为只读。

## 2. 基本用法

推荐使用 `mindmap` 围栏，内容使用无序列表。没有 H1 时，组件会自动补充默认根主题 `root`。

输入：

````md
```mindmap

- item1
- item2

```
````

输出：

```mindmap
- item1
- item2
```

## 3. 设置根主题标题

标题解析优先级为：

1. `mindmap` 围栏中的 `[title]`
2. Markdown 内容中的 H1
3. 默认标题 `root`

### 3.1. 围栏标题

````md
```mindmap [项目架构]
- Web 应用
- VSCode 插件
- Core 预览
```
````

```mindmap [项目架构]
- Web 应用
- VSCode 插件
- Core 预览
```

### 3.2. Markdown H1

````md
```mindmap
# TNotes Mindmap

- mindmap-web
- mindmap-core
- mindmap-vscode
```
````

```mindmap
# TNotes Mindmap

- mindmap-web
- mindmap-core
- mindmap-vscode
```

## 4. 控制默认展开层级

围栏名称后的数字表示默认展示到第几级子节点，最小值为 `1`：

- `1`：展示根节点和一级子节点。
- `2`：展示根节点、一级子节点和二级子节点。
- `3`：继续展示到三级子节点，以此类推。

标题和层级可以组合使用，例如：

````md
```mindmap [学习计划] 1
- item 1
  - item 1.1
    - item 1.1.1
  - item 1.2
- item 2
  - item 2.1
```
````

一级展开：

```mindmap [学习计划] 1
- item 1
  - item 1.1
    - item 1.1.1
  - item 1.2
- item 2
  - item 2.1
```

二级展开：

```mindmap [学习计划] 2
- item 1
  - item 1.1
    - item 1.1.1
  - item 1.2
- item 2
  - item 2.1
```
